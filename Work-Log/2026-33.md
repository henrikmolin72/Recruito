## CV prompt-injection defense (AI screening)
Layered, no new dependencies — protects the CV→AI-screening path from embedded instructions (visible or hidden text) in uploaded CVs.

- **Prompt layer:** eval prompt now declares the CV untrusted data, model self-reports via `INJECTION_CHECK: CLEAN|SUSPECTED` marker, Section D gains an injection audit row; client-report pass treats inputs as data-not-instructions.
- **Deterministic layer:** fixed a real bug — `FINAL_MATCH_SCORE` parse was first-match-wins, so an echoed injected marker beat the model's real final line; now last-match-wins. New `INJECTION_CHECK` parser (last-match-wins) + regex scan of `.txt` CVs (marker spoofing, "ignore previous instructions", zero-width runs). Report renderer strips links/images (kills injected phishing links / tracking pixels).
- **Consequence:** `candidate_screenings.injection_flagged` (migration 072) — a flagged run **never** auto-writes `ai_match_score`; amber review badge for admin + recruiter; company never sees the flag; `ai_audit_log` records the flag + which `.txt` scan patterns hit.
